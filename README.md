
# Apex Academy - Modern Educational & School HTML5 Template

A premium, responsive, and high-performance multi-page website template designed for modern private schools, high schools, colleges, and educational academies. Built using Tailwind CSS, Vanilla JavaScript, and AOS animations with zero build-step dependencies.

---

## 🌟 Key Features

- **Dark & Light Mode Toggle:** Smooth theme transition with user preference saved in LocalStorage.
- **Royal Navy & Gold Palette:** Prestigious Ivy-League / Oxford inspired academic color scheme.
- **Interactive Student Portal (Demo):** Roll Number based dashboard (`ID: 101`, `102`) showing attendance, report cards, and fee receipt status.
- **Live Tuition Fee Calculator:** Real-time client-side calculation based on grade, transport zones, and sibling discounts.
- **Live Event Countdown Timer:** Dynamic JavaScript countdown for upcoming sports galas and academic events.
- **Campus Video Tour Lightbox:** Fullscreen responsive video modal.
- **Filterable Photo Gallery:** Interactive categories with high-resolution image lightbox preview.
- **Smart WhatsApp Widget:** Floating conversion dock with pre-filled inquiry options.
- **Working Admission Form:** Serverless setup ready for Web3Forms or Formspree.
- **100% Royalty-Free Assets:** Clean Unsplash commercial-use imagery included.
- **Multi-Page Structure:** Includes `index.html` (Home) and `programs.html` (Academic Wings).
